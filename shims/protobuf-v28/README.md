# Protobuf v28 compatibility library

This directory contains the minimal lite-library source and headers from AOSP
`platform/external/protobuf`, tag `android-9.0.0_r61`, commit
`50b8bd8e0bcbecd5e1646106e0333556179bd2e7`.

It builds a private vendor library for the OPM7 Widevine engine. The source is
kept here so the Angler trees remain self-contained in an otherwise unmodified
LineageOS 22.2 checkout; no donor or stock framework binary is copied.
